# To-Do List (โปรแกรมบันทึกงานแบบ CLI)

Simple command-line To-Do List program (ภาษาไทย) ที่เก็บงานในหน่วยความจำและสามารถบันทึก/โหลดจากไฟล์ `tasks.json`.

## คุณสมบัติหลัก
- เพิ่มงานใหม่ (title, description, due_date)
- ดูงานทั้งหมด
- แก้ไขงาน
- ลบงาน (มีการยืนยัน)
- บันทึกและโหลดงานจาก `tasks.json` เมื่อเริ่ม/ปิดโปรแกรม

## การติดตั้ง
1. ติดตั้ง Python 3.8+ (แนะนำ 3.10+)
2. ไม่มี dependencies ภายนอกเพิ่มเติม — ใช้ไลบรารีมาตรฐานของ Python

## การรัน
เปิด Terminal/PowerShell แล้วรันคำสั่ง (จากโฟลเดอร์โปรเจค):

```powershell
python main.py
```

หรือระบุพาธเต็มของไฟล์:

```powershell
python ".............\AiCode\ToDoList_AI_1\main.py"
```

เมื่อโปรแกรมเริ่ม จะโหลดงานจาก `tasks.json` (ถ้ามี)

## ตัวอย่างการใช้งาน
1. เลือกตัวเลือก `1` เพื่อเพิ่มงานใหม่
   - ใส่ `ชื่อเรื่อง`, `รายละเอียด`, `วันครบกำหนด`
2. เลือกตัวเลือก `2` เพื่อดูงานทั้งหมด จะเห็นลำดับ ชื่อ วันครบกำหนด และสถานะ
3. เลือกตัวเลือก `3` เพื่อแก้ไขงาน (เลือกงานโดยลำดับ)
4. เลือกตัวเลือก `4` เพื่อลบงาน (มีการยืนยันก่อนลบ)
5. เลือกตัวเลือก `5` เพื่อออกจากโปรแกรม — ข้อมูลจะถูกบันทึกลง `tasks.json`

## รูปแบบข้อมูล
- `tasks.json` จะเก็บรายการงานเป็น list ของ object แต่ละ object มี key:
  - `id` (int)
  - `title` (string)
  - `description` (string)
  - `due_date` (string)
  - `completed` (bool)

## หมายเหตุ
- โปรแกรมเก็บข้อมูลในไฟล์ `tasks.json` ในโฟลเดอร์เดียวกับ `main.py`.
- หากต้องการเพิ่มฟีเจอร์ (เช่น ค้นหา, filter, ใช้ฐานข้อมูล) ให้บอกได้ ผมจะช่วยออกแบบและติดตั้งให้
